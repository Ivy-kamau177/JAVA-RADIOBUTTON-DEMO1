# RadioButtonDemo (Java Assignment 2)

A Java Swing application that uses five radio buttons (Bird, Cat, Dog, Rabbit, Pig)
to let the user choose a pet.

## Features
- Five radio buttons in a `ButtonGroup` (only one can be selected)
- A picture of the chosen pet is displayed
- A message box (`JOptionPane`) shows the user's selection

## How to run
1. Install the JDK (Java 8 or later)
2. Compile: `javac RadioButtonDemo.java`
3. Run: `java RadioButtonDemo`
